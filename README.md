# Боси Altgard

Таймери респавну польових босів AION 2 на карті Altgard, сервер Hadala (Європа, асмодіани).

Сторінка: https://skathy.github.io/hadala-bosses/

Дані беруться з відкритої стрічки A2Tools DPS Meter (`https://cdn.a2tools.app/feeds/boss-timers/2310.json`). Її збирають зі звітів гравців, у яких запущений метр. Сторінка оновлює дані кожні 30 секунд. Зірочки, фільтр і сповіщення зберігаються лише у твоєму браузері.

Один файл, `index.html`, без збирання і залежностей.
